# Policies

The public policies for the OpenWorld apps. They follow [legal-review.md](../legal-review.md) §3, §4.5, §8 and §13, and they describe only what the code does ([data-flow.md](../data-flow.md)).

| Policy | Required by | Shown |
| --- | --- | --- |
| [Terms of Use](terms.md) | legal-review §4.5; store binaries need their own terms, since Apache-2.0 covers only the source. Section 16 is Apple's required EULA terms. | First-run screen and About in every app |
| [Privacy Policy](privacy.md) | Apple 5.1.1(i), Google Play, CCPA | First-run screen and About; App Store Connect and Play Console need its URL |
| [Biometric Data Policy](biometric.md) | BIPA §15(a), Texas CUBI, Colorado HB24-1130, if they apply | First-run screen and About |
| [Consumer Health Data Privacy Policy](washington-health-data.md) | Washington My Health My Data Act, if it applies | About, and the website's home page |
| [Licenses](third-party.txt) | Every third-party license (legal-review §9) | About. Generated by `scripts/notices.py`; CI fails when it is out of date |

The apps carry these texts inside the library (`core/openworld-core/src/legal.rs`), so they read offline and match the build. The first-run screen asks for acceptance of `legal::VERSION` and keeps the accepted version only on the device. **When the Terms, the Privacy Policy, or the Biometric Data Policy change, change their Effective date and `VERSION` in the same commit**, so every user is asked again.

A policy that says something the app does not do is itself a deception risk (FTC Act §5), so any change to the data flow changes these files in the same commit.

## Contact address: change it when the domain changes

The contact is **support@onexengineering.com for now**. The owner plans to move to a different domain. When that happens, change every copy in one commit:

- `CONTACT` in `core/openworld-core/src/legal.rs`;
- the Contact section of each policy here, and section 14 and 17 of the Terms (`grep -rn onexengineering docs core`);

Changing the address does not by itself need a new `VERSION`, but an old address must keep working (forward it) for at least a year, because arbitration notices and opt-outs may be sent to it.
