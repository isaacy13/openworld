# Agents

Read [docs/handoff.md](docs/handoff.md) first. Treat the specs in [docs/](docs/) as locked decisions. Do not relitigate them. If two specs disagree, [docs/handoff.md](docs/handoff.md) and the later corrections win.

Phone `complete` scans are allowed after the user sees the estimate. Downscale is a prompt. Fast is the pre-selected bundle. Accurate is selectable and not measured yet. A 64 px short side on the detection image means the detector saw a face. Compare only when the original-frame crop is about 112 px short side. A tap opens that poster’s FBI URL. There is no poster-signing server. There is no release yet, so do not invent a SHA-256. When a release exists, the checksum is filled from that GitHub release. A checksum shipped beside the binary is not the check. Coverage policies and fail-closed rules stay as written in the specs.
