# Security

## Reporting a vulnerability

Please report security issues privately through GitHub: **Security → Report a vulnerability** on [isaacy13/openworld](https://github.com/isaacy13/openworld/security/advisories/new). Do not open a public issue. Include the version or commit, the platform, and steps or a file that reproduces it. Do not send photos of real people; a synthetic file is enough.

We aim to acknowledge a report within 7 days and to agree on a disclosure date with you.

## In scope

- Anything that sends a user's media, crops, or templates off the device.
- Anything that lets a non-official bundle, a changed cutoff, or a tampered poster pack pass as official.
- A file that crashes the app, exhausts memory, hangs a scan, or deletes or overwrites files it should not.
- A scan that reports complete or "no candidate" when frames were not analyzed.
- Opening a URL that is not the poster's own FBI page.

See [docs/threat-model.md](docs/threat-model.md) for the full model.

## Supported versions

There is no release yet. Fixes land on the default branch.
